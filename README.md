# Portfolio — Èric Casanovas Pérez

Portfolio personal (Astro + GitHub Pages) para mostrar proyectos personales de IA, automatización y
productividad. Trilingüe ES/EN/CAT (se maqueta ES primero).

## Desarrollo

```sh
npm install      # instalar dependencias
npm run dev      # servidor local en http://localhost:4321  (raíz → /es/)
npm run build    # build estático en dist/
npm run preview  # previsualizar el build
```

## Stack
Astro (SSG), i18n nativo (defaultLocale `es`), CSS a mano (sin librerías de UI). Deploy a GitHub Pages
como user site (`erico089dev.github.io`).
